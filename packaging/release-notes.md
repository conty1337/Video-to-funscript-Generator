## Installation

1. `Video-to-Funscript-x86_64.AppImage` herunterladen
2. Ausführbar machen: `chmod +x Video-to-Funscript-x86_64.AppImage`, oder in Dolphin per Rechtsklick → Eigenschaften → Berechtigungen → „Ausführbar“
3. Starten. Optional mit **Gear Lever** (Discover) ins Startmenü aufnehmen

Ab dieser Version aktualisiert sich die App selbst: Beim Start sucht sie nach einer neuen Version, lädt sie im Hintergrund, prüft sie per SHA-256 und ersetzt die AppImage-Datei. Der nächste Start oder „Neu starten“ in der Statusleiste nutzt dann die neue Version. Abschaltbar unter Hilfe → „Automatisch aktualisieren“.

Änderungen: siehe die gemergten Pull Requests in diesem Repository.
